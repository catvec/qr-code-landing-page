# QR Code Landing Page
Allows you to create QR codes with their content defined by query parameters.

# Table Of Contents
- [Overview](#overview)

# Overview
Useful for when you want to make a QR code with private information which can be viewed by the scanner, but now publish that information publically.

Host the `.html` files in this repository with any standard web server (Or GitHub pages). Use [[new.html]] as a convenient form to create links. The [[index.html]] page will display those links.
